# test-sdlc

A deliberately minimal Vite + React + TypeScript app that serves as a target repository for an AI agent that opens pull requests. It has one page with a header and a `Greeting` component, plus ESLint, Vitest, and a GitHub Actions CI workflow so automated changes can be linted, tested, and built.

## Commands

```sh
npm install      # install dependencies
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run lint     # run ESLint
npm run test     # run Vitest once
```
